### 📌 Featured Project

#### 🗺️ Chemnitz Map — Kulturhauptstadt 2025 Platform  
**Tech:** Angular · Express · MongoDB · Self-hosted Server

🔗 Live: https://katsala.com/chemnitz-map/

A gamified, location-based web platform developed for Kulturhauptstadt Chemnitz 2025.

**Key Features:**
- Multi-user system
- Real-time location-based check-ins
- Gamification with ratings and rankings
- Mobile-first responsive design
- Secure backend API
- Deployed and maintained on a private server

**Purpose:**
Encourages users to explore cultural locations in Chemnitz and engage with the city through interactive challenges.
